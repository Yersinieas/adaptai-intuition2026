# AdaptAI: Universal AI-Powered Adaptive Accessibility
**iNTUition 2026 IEEE Hackathon**

## The Problem
Digital interfaces are often "one-size-fits-all," creating barriers for users with varying physical or cognitive abilities. Traditional accessibility tools are often static and require manual configuration.

## Our Solution: AdaptAI Widget
A universal, AI-driven widget that dynamically adapts app interfaces based on real-time user intent and needs.

### Key Features
- **Real-time AI Intent Detection**: Predicts what the user wants to achieve (e.g., "Find Bus Route").
- **Dynamic Adaptation**: Switches between *Independent Mode* and *Assisted Mode* based on an "Independence Score."
- **Multimodal Input**: Supports Voice, Touch, and Gesture control seamlessly.
- **Low Latency**: High-speed processing (approx. 45ms) for a smooth user experience.

## Demo: Singapore Bus App
- Shows how the widget integrates into a high-utility app.
- Real-time metrics tracking (Confidence, Latency, Independence Score).

## Tech Stack
- Frontend: React / Next.js (for the demo)
- AI Engine: Transformer-based intent recognition
- Backend: Python (FastAPI/Flask)

## Future Impact
- Scale to all mobile and web applications.
- Empowering independence for the elderly and people with disabilities.
